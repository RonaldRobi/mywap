untuk semua peranan (Admin, Superadmin, Member). Ia boleh digunakan sebagai bahan
untuk mengemas kini slaid pembentangan.

## 4. UNDIAN — QR Code Maklum Balas Peserta Program

**Objektif:** Menambah **kod QR** pada modul undian supaya peserta program boleh
memberi maklum balas (contoh: maklum balas poster program) dengan mengimbas kod QR
— **tanpa perlu log masuk**.

**Aliran:**
1. Admin buka modul **Pengurusan Undian** → butang **QR** pada setiap undian
   (atau di halaman Keputusan).
2. Halaman QR memaparkan kod QR + URL, dengan butang **Salin**, **Muat Turun PNG**
   (resolusi tinggi untuk dicetak pada poster) dan **Pratonton**.
3. Kod QR diimbas oleh peserta → halaman jawab awam terbuka terus (tiada log masuk).
4. Maklum balas dihantar dan direkod sebagai **"Tanpa Nama"** dalam senarai
   keputusan / eksport CSV.

**Ciri teknikal:**
- Halaman awam baru: `GET/POST /polls/public/{poll}` — boleh diakses tanpa log masuk.
- Respon tanpa nama dibenarkan (`poll_responses.user_id` dibuat `nullable` melalui
  migrasi DB).
- Kod QR dijana dengan tahap pembetulan ralat tinggi (`errorCorrection H`) supaya
  mudah diimbas walaupun separa terhalang (contoh: dicetak pada poster).
- Halaman awam disokong sistem dwi-bahasa (`t()`) dan mesra telefon.

## 5. VIDEO — Sokongan Link YouTube Live

**Masalah:** Link YouTube biasa (`watch?v=`, `youtu.be`, `shorts`, `embed`) boleh
di-upload, tetapi **link jenis live** (`https://www.youtube.com/live/VIDEO_ID`) ditolak
dengan mesej "URL YouTube tidak sah".

**Punca:** Fungsi pengekstrak ID video tidak mengenali format `/live/`, jadi
`youtube_id` tidak dapat diambil.

**Penyelesaian:**
- `app/Http/Controllers/VideoController.php` — corak `/youtube.com/live/{ID}` ditambah
  pada `extractYoutubeId`. Sekarang format berikut disokong:
  `watch?v=`, `youtu.be`, `embed`, `shorts`, dan **`live`** (termasuk varian
  `m.youtube.com/live/` dan `?feature=share`).
- `resources/js/Pages/VideoManage.vue` — regex preview thumbnail turut dikemas kini
  supaya gambar thumbnail papar untuk link live.
- Embed video tetap guna `https://www.youtube.com/embed/{ID}` — jadi live stream
  terus boleh ditonton selepas ID berjaya diekstrak.

> **Nota:** Jika live stream ditetapkan *members-only* atau *disable embedding* oleh
> pemilik saluran, YouTube sendiri akan menyekat tayangan embed — perkara ini di luar
> kawalan sistem.

## 6. PROGRAM — Kemaskini Info, Tempoh & QR Kehadiran

**Objektif:** Membaiki tiga isu dalam modul Program & Acara — (1) tiada pilihan tempoh
untuk 1 hari / separuh hari, (2) maklumat program tidak dapat dikemas kini, dan
(3) QR kehadiran tidak dapat dimuat turun serta senarai kehadiran tidak lengkap.

### 6.1 Pilihan Tempoh Program (Separuh Hari / 1 Hari / Tempoh Khas)

- Dropdown **Tempoh** ditambah dalam borang **Tambah Program** dan **Edit Program**.
- **Separuh Hari** → auto-isi masa tamat: mula sebelum 12 tengah hari → **12:00**;
  mula 12 tengah hari atau lebih → **18:00**.
- **1 Hari** → auto-isi masa tamat **17:00** (tempoh kerja biasa 8 pagi – 5 petang);
  masih boleh diubah secara manual untuk program yang berjalan sehingga malam.
- **Tempoh Khas** → tetapkan masa sendiri (kelakuan asal).
- Masa tamat sentiasa boleh diubah manual; apabila masa mula dipilih dan tempoh
  belum ditetapkan, masa tamat diisi secara automatik.

### 6.2 Kemaskini Info Program (Bug Dibaiki)

- **Punca:** ID organisasi tidak disertakan dalam data program yang dihantar ke
  borang edit, jadi sistem menghantar `organization_id` sebagai teks kosong semasa
  menyimpan → pangkalan data menolak kemaskini (ralat foreign key) → kemaskini
  program sentiasa gagal.
- **Penyelesaian:** ID organisasi kini disertakan dalam data program; `organization_id`
  kosong ditukar kepada `null` di peringkat backend (create & update); borang edit
  menghantar nilai yang betul.
- **Kesan:** Simpan / kemas kini program kini berjaya, termasuk program
  "Semua Organisasi".

### 6.3 Muat Turun QR Kehadiran

- Endpoint baharu `events.qr.download` menjana **PNG resolusi tinggi (1024px)**.
- Butang **Muat Turun QR** ditambah di halaman papar QR (mod projektor), di halaman
  program (tindakan pentadbir), dan pautan **QR PNG** dalam senarai Kehadiran Program.
- QR dijana dengan tahap pembetulan ralat tinggi (`errorCorrection H`) supaya mudah
  diimbas walaupun dicetak separa terhalang.
- **Teknikal:** menggunakan Imagick jika tersedia; jika tidak, sistem menggunakan
  **renderer GD tulen** sebagai gantian supaya muat turun PNG tetap berfungsi tanpa
  extension Imagick.

### 6.4 Senarai Kehadiran Tidak Lengkap (Bug Dibaiki)

- **Punca:** penapis multi-tenancy (`OrganizationScope`) menapis peserta daripada
  organisasi lain apabila melihat kehadiran program "Semua Organisasi" → nama peserta
  dipaparkan sebagai **"Ahli Dibuang"**.
- **Penyelesaian:** senarai kehadiran (paparan program, senarai cetak) kini memuatkan
  peserta **tanpa penapis organisasi** — nama, telefon dan e-mel peserta daripada
  semua organisasi dipaparkan dengan betul.

## 7. INFO TERKINI — Padam Kategori (Bug Dibaiki)

**Aduan admin:** Dalam pengurusan **Kemas Kini Organisasi (Info Terkini)**, bahagian
kategori hanya boleh **tambah** — tidak boleh padam.

- **Punca:** fungsi `storeCategory` wujud tetapi tiada fungsi padam kategori; paparan
  "Tambah Kategori" tidak menunjukkan senarai kategori sedia ada.
- **Penyelesaian:**
  - Kaedah baharu `NewsController::destroyCategory` + route `DELETE
    /admin/info-terkini/categories/{newsCategory}`.
  - Seksyen "Tambah Kategori" kini memaparkan **Senarai Kategori** dengan butang
    **Delete** pada setiap kategori (dengan pengesahan sebelum padam).
  - Padam kategori **selamat**: siaran/berita yang menggunakan kategori itu hanya
    kehilangan kategori (`nullOnDelete`) — tiada data dipadam bersama.

## 9. YURAN AHLI — Notifikasi Tahunan & "Lunas" → "Selesai"

### 9.1 Invois / Notifikasi Yuran Tahunan (setiap awal tahun)

**Objektif:** Setiap awal tahun, ahli diberi invois/notifikasi untuk membayar yuran
tahun baharu (contoh: tahun 2027).

- **`fees:notify-start-of-year`** (command baharu) — menghantar notifikasi dalam-app
  kepada semua ahli dengan yuran belum dibayar untuk tahun berkenaan, termasuk
  jumlah bayaran dan pautan ke halaman bayaran.
- **Jadual automatik** pada **1 Januari** setiap tahun (waktu Malaysia):
  1. `fees:generate` — cipta rekod yuran tahun baharu.
  2. `fees:notify-start-of-year` — hantar notifikasi kepada ahli yang belum bayar.
- **Loceng notifikasi** kini **boleh diklik** — notifikasi yuran membawa terus ke
  halaman bayaran (`action_url`).

### 9.2 "Lunas" → "Selesai"

Status yuran yang sebelum ini dilabel **"Lunas"** kini **"Selesai"** — ditukar dalam
halaman **Yuran Ahli** (penapis, label, statistik), **Pengurusan Ahli** (badge), dan
eksport PDF yuran.

## 10. PENDAFTARAN AHLI — Penambahbaikan

### 10.1 Surat Pengesahan Keahlian

- Butang **Surat Pengesahan** di halaman **Kad Ahli** (log masuk ahli) → muat turun
  **PDF rasmi** surat pengesahan keahlian.
- Surat mengandungi: kepala surat organisasi, butiran ahli (nama, no ahli, no IC,
  organisasi, cawangan, negeri, tarikh mula keahlian, emel, telefon) dan ruang
  tandatangan.
- Dijana menggunakan **DomPDF** (sudah dipasang dalam projek).

### 10.2 Kad Ahli

Kad Ahli digital sedia ada kini lengkap dengan tindakan:
- **Cetak PDF** (print), **Muat Turun** (JPG) dan **Kongsi** — sedia ada.
- **Surat Pengesahan** (PDF) — **baharu** (lihat 10.1).

### 10.3 Notis Pembayaran Yuran Tahunan

- Setiap **1 Januari** (waktu Malaysia), sistem:
  1. `fees:generate` — cipta rekod yuran tahun baharu (cth. 2027).
  2. `fees:notify-start-of-year` — hantar **notis pembayaran yuran tahunan** kepada
     ahli yang belum membayar.
- Notis dihantar melalui **loceng notifikasi** (in-app) dengan pautan terus ke halaman
  bayaran.

### 10.4 Hebahan Program Melalui WhatsApp — **DITANGGUHKAN (skip)**

- **Status:** Tidak dilaksanakan.
- **Sebab:** API WhatsApp Business memerlukan **langganan berbayar yang tinggi** dan
  proses kelulusan; kos tidak wajar untuk fungsi ini.
- **Cadangan alternatif:** guna notifikasi in-app / e-mel (sedia ada), atau kongsi
  pautan program secara manual kepada ahli.

### 10.5 Laporan Jumlah Keseluruhan Keahlian & Negeri

- Butang **Muat Turun Laporan** ditambah pada seksyen **"Jumlah Ahli Mengikut Negeri"**
  di dashboard pentadbir.
- Laporan CSV mengandungi **jumlah keseluruhan ahli**, **peratusan**, dan **pecahan
  mengikut negeri** (serta "Tidak Dinyatakan" bagi ahli tanpa negeri).
- Boleh difilter ikut organisasi (admin bukan superadmin hanya melihat organisasi
  sendiri).

## 11. TEMPAHAN & PERKHIDMATAN/FASILITI — Penambahbaikan

**Aduan admin:**
1. Makluman tempahan hanya ada bahagian nama — tiada nombor contact.
2. Tempahan perlu pilihan hari dan masa dalam satu borang.
3. Buka tempahan kepada **orang luar**, dan tambah **option harga ahli**.
4. Label **"Urus Ruang"** perlu ditukar kepada **"Perkhidmatan/Fasiliti"**.

### 11.1 Nombor Contact (Makluman Tempahan)

- Borang tempahan kini ada medan **Nama** + **Nombor Telefon** (pre-fill dari profil
  untuk ahli; wajib untuk orang luar).
- Senarai tempahan admin (pentadbir) kini memaparkan column **Contact** (nama + no
  telefon) untuk setiap tempahan.

### 11.2 Pilihan Hari & Masa Dalam Satu Borang

- Dua input `datetime-local` digantikan dengan satu borang: **Tarikh** (date) +
  **Masa Mula** (time) + **Masa Tamat** (time).
- Jika masa tamat lebih awal daripada masa mula, ia dianggap tamat pada keesokan
  hari (tempahan semalaman).
- Anggaran harga dikira secara langsung (live) berdasarkan tarikh & masa yang dipilih.

### 11.3 Tempahan Terbuka Kepada Orang Luar + Harga Ahli

- Route tempahan dipindah ke **public** (`/perkhidmatan`) — orang luar boleh imbas &
  tempah tanpa log masuk (isi nama + nombor telefon; `user_id` menjadi `nullable`).
- Setiap fasiliti kini boleh ada **dua harga**: **Harga Umum** (`price_per_unit`)
  dan **Harga Ahli** (`member_price_per_unit`, opsyenal).
- Ahli yang log masuk otomatik mendapat **Harga Ahli**; orang luar membayar
  **Harga Umum**. Jika Harga Ahli kosong, semua bayar Harga Umum.
- Ahli yang log masuk masih boleh lihat sejarah tempahan sendiri.
- Pautan awam "tempah Perkhidmatan/Fasiliti" ditambah di halaman log masuk untuk
  orang luar.

### 11.4 Penamaan Semula — Perkhidmatan/Fasiliti

- Label menu: group **"Kemudahan" → "Perkhidmatan/Fasiliti"**,
  **"Urus Ruang" → "Urus Perkhidmatan/Fasiliti"** (pentadbir),
  **"Tempahan Ruang" → "Tempah Perkhidmatan/Fasiliti"** (ahli).
- Tajuk halaman & butang turut dikemas kini (Tambah/Senarai Perkhidmatan/Fasiliti,
  Senarai Tempahan, dll).

## 12. Penambahbaikan Sistem — Maklum Balas Pengguna (Mac/Apr 2026)

### 12.1 Pautan Media Sosial & Laman Web
6 kolum baharu pada `organizations`: `website_url`, `facebook_url`, `instagram_url`,
`twitter_url`, `youtube_url`, `tiktok_url`. UI input di **Superadmin → Organisasi**.
Ikon media sosial dipaparkan di **footer** AppLayout (klik buka tab baru).

### 12.2 Program — Edit & Delete UI
Butang **Edit** (pensel → halaman Show) & **Padam** (tong → pengesahan × dialog)
pada kad program di Index. Route `DELETE /events/{event}`.

### 12.3 Broadcast — Penyasaran Cawangan
Pilihan **"Ahli Cawangan"** + kolum `branch_id` + penapisan di `SendBroadcastJob`.
UI pemilih cawangan di halaman Broadcast.

### 12.4 Live Stream — Penanda LIVE
Toggle **"Sedang Langsung (LIVE)"** pada borang Video (admin). Kolum `is_live`
pada jadual `videos`. Nota: penanda untuk paparan masa depan di dashboard.

## 13. TRANSAKSI — Carian, Tapisan Tarikh & Eksport CSV

**Aduan tester:** *"Susah nak detect transaksi."*

### 13.1 BayarCash — Elak Transaksi Pendua (Idempotency)

**Aduan tester:** Transaksi kadangkala muncul lebih dari sekali.

- **Punca:** Callback daripada gateway BayarCash boleh dihantar **lebih daripada
  sekali** (retry). Sistem lama memproses setiap callback sebagai transaksi baru.
- **Penyelesaian:** Callback kini menyemak status transaksi dahulu — jika sudah
  **Berjaya / Gagal / Dipulangkan**, callback pendua **diabaikan**.
- **Kesan:** Tiada lagi double-count yuran, infaq, atau pesanan; tiada donasi
  berkala berganda.

4. Halaman maklum balas awam terbuka **tanpa log masuk** — jawab semua soalan dan
   hantar.
5. Semak halaman Keputusan — respon baharu direkod sebagai **"Tanpa Nama"**.

### Video (YouTube Live)

1. Log masuk sebagai Admin → menu **Video** → Cipta Video.
2. Tampal link live seperti `https://www.youtube.com/live/VIDEO_ID` (atau dengan
   `?feature=share`).
3. Sahkan video diterima (tiada lagi mesej "URL YouTube tidak sah") dan thumbnail
   papar.
4. Buka halaman Video sebagai Member → video live boleh dimainkan.

### Program (Events)

1. Log masuk sebagai Admin / Superadmin → **Program & Acara** → **Tambah Program**.
2. Pilih **Tempoh** = *Separuh Hari* atau *1 Hari*, tetapkan masa mula → sahkan masa
   tamat diisi secara automatik (12:00/18:00 atau 17:00).
3. Buka program sedia ada → **Edit Program** → ubah tajuk/masa → **Simpan Perubahan**
   → sahkan mesej "Program berjaya dikemas kini".
4. Di halaman program, klik **Muat Turun QR** → fail PNG dimuat turun dan boleh
   diimbas.
5. Rekodkan kehadiran (peserta imbas QR) → sahkan senarai kehadiran memaparkan nama
   peserta daripada semua organisasi (tiada lagi "Ahli Dibuang").

### Info Terkini (Padam Kategori)

1. Log masuk sebagai Admin / Superadmin → menu **Info Terkini (Kemas Kini Organisasi)**
   → pengurusan.
2. Bahagian **Tambah Kategori** kini memaparkan **Senarai Kategori** sedia ada.
3. Klik **Delete** pada mana-mana kategori → sahkan dialog pengesahan.
4. Sahkan kategori hilang daripada senarai dan siaran lama yang menggunakan kategori
   itu masih wujud (cuma kategori jadi "Umum").

### AHLI (Dashboard Ahli)

1. Log masuk sebagai Member → dashboard ahli.
2. Sahkan **tiada lagi kad "Status Yuran"** / teks "Yuran Tertunggak".
3. Pada **Kad Ahli**, sahkan stat memaparkan **Cawangan Ahli** (bukan Usrah) dan
   **Sejak**.
4. Pintasan **"Yuran Saya"** masih membuka halaman Kewangan untuk semakan/bayaran.

### YURAN AHLI (Notifikasi Tahunan & Label)

1. Jalankan `php artisan fees:generate 2027` kemudian
   `php artisan fees:notify-start-of-year 2027` (atau tunggu jadual 1 Januari).
2. Sahkan ahli yang belum bayar menerima notifikasi "Yuran Keahlian 2027" di loceng
   notifikasi, dan notifikasi itu boleh diklik terus ke halaman bayaran.
3. Di halaman **Yuran Ahli** (admin), sahkan status yang dibayar memaparkan
   **"Selesai"** (bukan "Lunas") — termasuk penapis, statistik dan eksport PDF.

### Pendaftaran Ahli

1. Log masuk sebagai Member → **Kad Ahli**.
2. Klik **Surat Pengesahan** → fail PDF surat pengesahan keahlian dimuat turun
   (sahkan butiran ahli lengkap).
3. Log masuk sebagai Admin → dashboard → seksyen **Jumlah Ahli Mengikut Negeri**.
4. Klik **Muat Turun Laporan** → fail CSV mengandungi jumlah keseluruhan ahli dan
   pecahan mengikut negeri dimuat turun.

### Tempahan & Perkhidmatan/Fasiliti

1. Log masuk sebagai Admin → menu **Perkhidmatan/Fasiliti** → **Urus
   Perkhidmatan/Fasiliti**.
2. Tambah fasiliti — sahkan medan **Harga Umum** dan **Harga Ahli** (opsyenal).
3. Sebagai **orang luar** (log keluar) → buka `/perkhidmatan` (atau pautan di halaman
   log masuk) → pilih fasiliti → borang **Tarikh + Masa Mula + Masa Tamat** → isi
   **Nama** + **Nombor Telefon** → Hantar. Sahkan tempahan direkod sebagai "pending".
4. Log masuk sebagai **Ahli** → tempah fasiliti yang sama → sahkan kadar yang
   dipaparkan adalah **Harga Ahli** (jika ditetapkan) dan anggaran harga dikira
   dengan kadar tersebut.
5. Sebagai Admin → **Senarai Tempahan** → sahkan column **Contact** memaparkan nama
   + nombor telefon penempah (termasuk tempahan orang luar).
6. Sahkan menu/tajuk memaparkan **Perkhidmatan/Fasiliti** (bukan "Ruang").

> **Nota (WhatsApp):** Hebahan program melalui WhatsApp **tidak dilaksanakan**
> (kost API WhatsApp Business tinggi). Alternatif: notifikasi in-app / e-mel.

### Pautan Media Sosial & Laman Web

1. Log masuk sebagai Superadmin → **Organisasi** → buka mana-mana organisasi.
2. Buka <kbd>Pautan & Media Sosial</kbd> → isi URL (cth. laman web, Facebook).
3. Log masuk sebagai Member → sahkan ikon media sosial kelihatan di footer (klik
   buka tab baru).

### Program (Edit & Padam)

1. Log masuk sebagai Admin → **Program**.
2. Sahkan butang **pensel (edit)** dan **tong sampah (padam)** di penjuru setiap kad.
3. Klik pensel → pergi ke halaman Show (yang sudah ada borang edit).
4. Klik tong → sahkan dialog pengesahan → program dipadam.

### Broadcast (Cawangan)

1. Log masuk sebagai Admin → **Push Notification**.
2. Pilih sasaran **"Ahli Cawangan"** → pilih cawangan dari senarai → hantar.
3. Sahkan hanya ahli cawangan terpilih menerima notis (log masuk sebagai ahli
   tersebut untuk semak).

### Live Stream (Penanda LIVE)

1. Log masuk sebagai Admin → **Video** → tambah video.
2. Tandakan kotak **"Sedang Langsung (LIVE)"** → simpan.
3. Edit video sedia ada → toggle penanda LIVE.

### MyWAP Mall (E-Dagang)

1. Log masuk sebagai Member → **MyWAP Mall** → **Produk**.
2. Klik **"Tambah ke Bakul"** pada kad produk (2-3 produk berbeza).
3. Sahkan ikon troli di header menunjukkan kiraan item.
4. Klik ikon troli → halaman **Bakul Beli-belah** papar semua item, postage gabungan, + jumlah harga.
5. Laraskan kuantiti (butang +/−), padam item, kemudian klik **"Buat Pesanan"**.
6. Sahkan pesanan dicipta → redirect ke halaman Order.
7. **Public mall**: log keluar → buka `/mall` → sahkan produk dipaparkan → klik produk → tambah bakul → checkout (isi nama / nombor telefon) → pesanan berjaya.
8. **Harga ahli**: log masuk sebagai ahli → sahkan produk dengan harga ahli memaparkan badge "Ahli: RM X" dan harga dikira guna harga ahli semasa checkout.
9. **Regression — dashboard**: log masuk sebagai Admin & Member → sahkan **dashboard tidak blank** (ikon troli berfungsi, menu MyWAP Mall muncul).
10. **Regression — produk detail**: klik mana-mana produk dari `/mall` dan `/products` → sahkan halaman detail dimuat tanpa error `Undefined variable $request`.

### Transaksi (Carian, Tapisan & Eksport)

1. Log masuk sebagai Admin/Superadmin → **Transaksi** (atau **Semua Transaksi**).
2. Taip nama/emel/rujukan dalam kotak **Cari** → Enter → sahkan senarai ditapis.
3. Pilih **Dari/Hingga** tarikh → sahkan hanya transaksi dalam julat dipaparkan.
4. Sahkan badge jenis berwarna (Yuran/Infaq/Pesanan) dan status dalam Bahasa Melayu.
5. Klik **Eksport CSV** → fail dimuat turun mengandungi transaksi yang sedang ditapis.

### BayarCash (Elak Transaksi Pendua)

1. Buat pembayaran infaq/yuran yang berjaya.
2. Hantar callback BayarCash yang sama dua kali (simulasi gateway retry).
3. Sahkan transaksi kedua **diabaikan** — jumlah infaq/yuran tidak bertambah dua kali.

### Penderma

1. Log masuk sebagai Admin/Superadmin → **Penderma** (seksyen Kewangan).
2. Sumbang ke 2-3 kempen berbeza dengan emel yang sama → sahkan ia direkod sebagai
   **satu penderma** (bukan beberapa rekod).
3. Cari penderma melalui nama/emel → klik → halaman detail menunjukkan jumlah
   sumbangan dan sejarah semua kempen.

### Borang (Form Builder)

1. Log masuk sebagai Admin → **Borang** → **+ Borang Baru**.
2. Isi tajuk, tambah beberapa soalan (cuba jenis teks, radio, checkbox), tandakan
   **wajib**, susun soalan (↑/↓), tambah **emel penerima** → **Cipta Borang**.
3. Buka pautan awam `/borang/{token}` dalam tetingkap tanpa log masuk → isi & hantar.
4. Di senarai borang, klik **Jawapan (N)** → sahkan respons baharu muncul.
5. Klik **Eksport CSV** → jawapan dimuat turun.
6. Klik **Hantar** → emel jemputan "Buka Borang" dihantar ke emel penerima
   (semak log emel jika mailer=log).

### Tetapan Emel (Mailer)

1. Log masuk sebagai Superadmin → **Tetapan (myWAP Settings)** → **Tetapan Emel
   (Mailer)**.
2. Pilih kaedah: **Log** → Simpan. Masukkan emel ujian → **Hantar Emel Ujian** →
   sahkan mesej berjaya.
3. Tukar ke **Resend**, isi kunci API + From Address → Simpan → hantar emel ujian
   semula → sahkan mesej berjaya (email sebenar diterima jika mailer=resend).
4. Pilih **SMTP** → isi host/port/username/password → Simpan → hantar emel ujian
   untuk sahkan sambungan SMTP.
